Projeto Final — Organização Social

Descrição
Este projeto é o resultado final da disciplina de Desenvolvimento Web.  
Trata-se de uma aplicação web completa, responsiva e acessível, construída com **HTML5, CSS3 e JavaScript Modular (SPA)**, aplicando **boas práticas de Git/GitHub, Acessibilidade (WCAG 2.1)** e **otimização para produção**.

---

Funcionalidades
- Navegação **SPA** sem recarregar a página.
- **Validação de formulários** com mensagens dinâmicas.
- **Modo escuro e alto contraste** para acessibilidade.
- **Leitura por teclado e leitores de tela**.
- **Armazenamento Local** (`localStorage`) para dados persistentes.
- **Responsividade completa** em dispositivos móveis.
- **Versionamento GitFlow** com commits semânticos e releases organizadas.

---

Acessibilidade
- Conformidade com **WCAG 2.1 Nível AA**.
- Suporte completo para navegação por teclado.
- Contraste mínimo de 4.5:1.
- Alternância entre modo padrão e modo alto contraste.
- Etiquetas semânticas (`aria-label`, `role`, `alt`) aplicadas.

Versionamento
Adotado **GitFlow**:
